# 成长学习乐园

给一个孩子做的家庭学习项目，跟着他一个年级一个年级往上长。用他当下喜欢的东西编故事、做游戏，练识字、数学、英语和逻辑；动笔的事放到纸上，屏幕练不到的事交给家长。

- 形式：**故事 + 互动游戏 + 可打印的纸 + 每周给家长的一页**
- 设备：平板、手机、电脑的浏览器都能用，不用安装

目标是不变的，阶段和主题只是现在的情况：

| | 现在 | 以后 |
| --- | --- | --- |
| 目标 | 见下面“想培养什么” | 不变 |
| 阶段 | 5 岁，幼儿园中班 | 每年升一级：大班、一年级……一个年级一份大纲 |
| 主题 | “车车镇”：他现在喜欢车和列车，所以角色是五辆车 | 跟着他的兴趣换。兴趣变了，角色和故事跟着换 |
| 进度 | 中班的大纲已定（见 [docs/k2/plan.md](docs/k2/plan.md)），**第 1–2 周的内容已做好** | 后面的内容看他的反应再做 |

## 想培养什么

想让他长成一个**愿意学、坐得住、说得出、想得清、手上稳、处得来、有点子**的孩子，字、数和英语的底子跟着年级一层一层加上去。这一句不随年龄和主题变。

| 层 | 包括 | 说明 |
| --- | --- | --- |
| 一、学习品质 | 愿意学、坐得住 | 最先保。专注度在这里 |
| 二、能力 | 说得出、想得清、手上稳、处得来、有点子 | 逻辑思维在“想得清”里 |
| 三、知识 | 字、数、英语 | 照常教，数量只当参考，不当成绩 |

起冲突时上面的层优先：兴趣和进度冲突，进度让路；屏幕和纸、户外冲突，屏幕让路。

完整的目标和取舍规则在 [docs/aims.md](docs/aims.md)。它对照了哪些业界体系、和《3–6 岁儿童学习与发展指南》哪里一致哪里超出，在 [docs/systems.md](docs/systems.md)。

## 一周怎么过

每一周有三条路。屏幕只管它擅长的，其余交给纸和家长：

| 路 | 做什么 | 主要管什么 |
| --- | --- | --- |
| 屏幕 | 五天，每天一站三个活动，约十分钟 | 字、数、英语；想得清；听故事 |
| 纸 | 涂色、控笔、绘本、描红、练习、卡片 | 手上稳；坐得住；有点子 |
| 家长 | 每周一页“给家长”：聊一聊、玩一玩、看一看，加起来二三十分钟 | 开口说；处得来；愿意学 |

## 怎么打开

这是纯静态网页，没有后端，不需要安装或编译。

**在电脑上**：直接双击 `index.html`，或者在项目目录里运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

**在平板或手机上**：需要把这个目录放到任何一个静态网页托管上（例如 GitHub Pages：仓库 Settings → Pages → 选择分支和根目录），然后用设备的浏览器打开网址。打开后可以“添加到主屏幕”，像应用一样使用。项目更新以后，在设备上刷新一次页面。

## 孩子怎么用

1. 点一下小风，进入主页。
2. 点 🔑 **出发**：每天一站，一站有 3 个活动，大约 10 分钟。这一站玩好了，下一站才会打开。
3. 点 🎮 **自由玩**：已经开放的活动随便选。
4. 走到涂色那一步，屏幕会让他去拿纸和蜡笔，点一下蜡笔就可以离开屏幕去涂了。涂色纸需要家长提前打印。
5. 孩子还不识字，所有提示都会读出来；点右上角 🔊 可以再听一遍。
6. 每天用到上限（默认 15 分钟）后会显示“休息”画面。

孩子的页面上不说“任务”“完成”。每天的三个活动叫“一站”，想先玩哪个就点哪个。

## 家长怎么用

主页右上角点“家长”，答一道乘法题进入：

| 栏目 | 用途 |
| --- | --- |
| 概览 | 走过几站、得了几颗星、累计和今天用了多久 |
| 兴趣观察 | 各类内容的自由玩次数、时长、中途退出次数、答对率 |
| 识字 | 字库里每个字的掌握情况；点一下可以手动标记“认识 / 不认识” |
| 数学、英语 | 各项内容的答对率和当前难度 |
| 打印 | 按周一次打印这一周要用的纸，最前面是“给家长”的一页；也可以单独打印涂色页、控笔练习、绘本、描红、数学练习、英语卡片（A4） |
| 大纲 | 这个年级三个阶段的目标，已经做好了几周 |
| 设置 | 孩子的名字、每天时长上限、语速、音效、语音选择和试听 |
| 数据 | 导出、导入、清空学习记录；观察笔记 |

每周要做的事：

- **打印一次**。在“打印 → 按周打印”里把这一周的纸一次印出来。
- **看“给家长”那一页**。它排在这叠纸的最前面，分三块：聊一聊（故事的三个问题）、玩一玩（一两样不用屏幕的小游戏）、看一看（这一周留意他的三件事）。说、专注、和人相处这些事屏幕练不到，靠的是这一页。挑着做，不用做全。
- **记一句观察**。屏幕看不到纸上的事和他说的话，想到了就在“数据”里的观察笔记记一句。

第一次使用时：

- **标一遍认识的字**。在“识字”里把您确定他认识的字标出来，“认字”活动就只教他不会的字。
- **听一下声音**。朗读用的是设备自带的语音，程序会自动挑里面最自然的一个。“设置”里的语音按好坏排了序，标着“自然”或“较机械”，可以试听，也可以手动换。听着机械的话，“设置”里写了各种设备怎么装更好的声音。

## 现在有什么内容：中班 · 车车镇 · 第 1–2 周

| | 第 1 周　你好，车车镇 | 第 2 周　大石头挡路了 |
| --- | --- | --- |
| 故事 | 《小风来到车车镇》＋ 问答 | 《大石头挡路了》＋ 问答 |
| 识字 | 车 大 小 山 火 水 土 风；找字小侦探 | 石 上 下 来 去；认新字 |
| 数学 | 数车车、停车场、找数字 | 谁多谁少、数字公路、又来了几辆 |
| 英语 | car bus truck；red blue yellow | one–five；green；a red car |
| 逻辑、科学、安全 | 红绿灯 | 找规律、轮子实验室 |
| 纸 | 涂色（含一张列车）、控笔练习、绘本、描红、数一数、英语卡片 | 涂色、画一辆车、绘本、描红、写数字、比多少、英语卡片 |
| 给家长 | 聊：每辆车都有自己的本领；玩：反着做、路上认灯数车 | 聊：做不到可以请人帮忙、换个办法；玩：什么会滚、玩具车排队 |

车车镇的五个角色都是原创的，名字用的是最基础的汉字：小风（小汽车）、小火（消防车）、小水（洒水车）、阿土（挖掘机）、大山（大卡车）。

## 已知的限制

- **声音好不好取决于设备**。朗读用的是浏览器自带的语音合成，网页没法自己下载声音。设备上只有机械的声音时，需要家长按“设置”里的提示装一个更好的。没有中文语音时，屏幕上的文字需要家长读给孩子听。
- **语音没有在开发环境里听过**。开发环境没有扬声器和语音引擎，只验证了“没有语音时流程不会卡住”。声音的效果要在自己的设备上试听。
- **记录只在本机**。保存在浏览器里，换设备或清除浏览器数据会丢失，请用“导出记录”备份。无痕模式下不会保存。
- **描红页没有笔顺**，第一次写需要家长示范。
- **楷体依赖系统字体**。苹果设备和 Windows 自带楷体；多数安卓设备没有，会显示成黑体，不影响使用。

## 文档和目录

文档从上到下，每一份回答一个问题：

| 回答什么 | 在哪里 |
| --- | --- |
| 为了什么：想让他长成什么样 | [docs/aims.md](docs/aims.md) |
| 依据什么：业界的体系，这个项目借了什么 | [docs/systems.md](docs/systems.md) |
| 他现在怎么样：观察和每次的调整 | [docs/growth-log.md](docs/growth-log.md) |
| 这一年教什么：年级大纲 | [docs/k2/plan.md](docs/k2/plan.md) |
| 这一周做什么 | `content/k2/` 下，一周一个文件 |

目录分成三块：**程序**（`app/`，很少改）、**内容**（`content/`，一直增长）、**文档**（`docs/`）。

```
index.html              入口，双击即可打开
app/                    程序：页面和玩法。内容再多，这里也不用跟着改
  core/                 存储、语音和音效、绘图、课程登记处
  engines/              玩法，一个文件一种：选择题、卡片、故事、停车场、红绿灯、涂色、轮子实验室
  ui/                   孩子的页面、家长页、打印版式
  css/                  界面样式、打印样式
  main.js               路由和启动
content/                内容：按年级分档
  library/              各年级共用的字库、词库和反复出现的练习，按能力的五个方面分
    language/           说得出：识字、英语
    thinking/           想得清：数、逻辑、科学
    hands/              手上稳：涂色、控笔、写数字（都在纸上）
    social/             处得来：安全和规则
    creative/           有点子：画自己想的
  k2/                   幼儿园中班（现在）
    grade.js            这个年级的阶段目标
    w01.js              第 1 周：这一周的三条路、故事、新字新词、这一周自己的纸
    w02.js              第 2 周
docs/                   文档，见上面的表
tests/smoke.js          自动把所有活动玩一遍的测试
CLAUDE.md               给 Claude 的说明：做法的前提和程序上的约定
```

library 的五个目录对应“能力”的五个方面。哪个目录里东西少，就是哪个方面缺内容。

年级的代号和先后：

| 目录 | 年级 | 大约时间 | 状态 |
| --- | --- | --- | --- |
| `k2` | 幼儿园中班 | 2026 年 11 月 – 2027 年 8 月 | 进行中 |
| `k3` | 幼儿园大班 | 2027 年 9 月起 | 升班时再规划 |
| `g1` 起 | 小学一年级起 | 2028 年 9 月起 | 到时候再规划 |

没开始的年级不建目录，也不提前写内容。

## 怎么加一周内容

1. 先看 `docs/growth-log.md` 最后几条记录，再对照 `docs/aims.md` 和这个年级的大纲，定这一周教什么。
2. 复制上一周的文件，改成新的一周，例如 `content/k2/w03.js`。里面依次是：这一周（屏幕上五天的安排、要打印的纸、给家长的一页）、故事、这一周新教的字和词、这一周自己的纸。
3. 对照七个方面看一遍：故事带一个“心事”，有一项逻辑，有一张要花几分钟的纸，有一件由他定、没有标准答案的事。
4. 新字如果不在字库里，加到 `content/library/language/zh-chars.js`；新的英语词加到 `content/library/language/en-words.js`。
5. 在 `index.html` 里加一行 `<script src="content/k2/w03.js"></script>`，放在上一周的后面。
6. 运行测试，确认每个活动都能走通：

```bash
node tests/smoke.js
```

测试需要 [Playwright](https://playwright.dev/)。忘了第 5 步、活动 id 写错或重复、漏了给家长的一页、哪张纸的内容超出了纸面，测试都会直接报出来。

## 升到下一个年级时

1. 在 `docs/growth-log.md` 里写一条回看：这个年级学到了哪里、喜欢什么、不喜欢什么。
2. 据此写下一个年级的大纲，例如 `docs/k3/plan.md`。
3. 新建 `content/k3/grade.js`（照 `content/k2/grade.js` 写）和第一周的文件，在 `index.html` 里加载。

上一个年级没做完的内容不用补做；有用的并进新年级的大纲。

## 他的兴趣变了，换主题时

主题是入口，不是目的。用车，是因为他现在喜欢车，愿意为了车多看一眼、多听一句。

1. 每 12 周回看时问一句：他现在最爱说、最爱玩的是什么？结论记进 `docs/growth-log.md`。
2. 兴趣是慢慢变的，主题也可以慢慢换：先让新喜欢的东西进故事，当新角色或者新地方。列车就是这样，计划在第 3 周出场。
3. 真要整个换主题时：
   - **要重做的**：角色和画（`app/core/art.js` 现在只会画车和车的场景）、故事、孩子页面上的主角（现在是小风），以及画面和车绑在一起的几样练习（停车场、红绿灯、轮子实验室、数学题里的车）。
   - **不用动的**：培养目标、三条路、目录结构、选择题、卡片和故事这几种玩法、学习记录。

现在没有把主题做成可以切换的：还不知道下一个兴趣是什么，而新主题无论如何都要重新画、重新写故事。
