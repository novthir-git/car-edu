# 车车镇学习乐园

给喜欢汽车的 5 岁孩子做的启蒙学习项目：用原创的汽车角色讲故事，再用小游戏练习识字、数学、英语，并顺带试探他对美术、科学、逻辑等方向的兴趣。

- 形式：**故事 + 互动游戏 + 可打印的纸质材料**
- 设备：平板、手机、电脑的浏览器都能用
- 长期：内容**按年级分档**，一档一档往上加。现在是幼儿园中班这一档
- 进度：中班的大纲已定（见 [docs/k2/plan.md](docs/k2/plan.md)），**第 1–2 周的内容已做好**，后面的内容看孩子的反应再做

## 怎么打开

这是纯静态网页，没有后端，不需要安装或编译。

**在电脑上**：直接双击 `index.html`，或者在项目目录里运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

**在平板或手机上**：需要把这个目录放到任何一个静态网页托管上（例如 GitHub Pages：仓库 Settings → Pages → 选择分支和根目录），然后用设备的浏览器打开网址。打开后可以“添加到主屏幕”，像应用一样使用。

## 孩子怎么用

1. 点一下小风，进入主页。
2. 点 🔑 **出发**：每天一站，一站有 3 个活动，大约 10 分钟。这一站玩好了，下一站才会打开。
3. 点 🎮 **自由玩**：已经开放的活动随便选。
4. 走到涂色那一步，屏幕会让他去拿纸和蜡笔，点一下蜡笔就可以离开屏幕去涂了。涂色纸需要家长提前打印。
5. 孩子还不识字，所有提示都会读出来；点右上角 🔊 可以再听一遍。
6. 每天用到上限（默认 15 分钟）后会显示“休息”画面。

孩子的页面上不说“任务”“完成”。每天的三个活动叫“一站”，想先玩哪个就点哪个。

## 家长怎么用

主页右上角点“家长”，答一道乘法题进入：

| 栏目 | 用途 |
| --- | --- |
| 兴趣观察 | 各类内容的自由玩次数、时长、中途退出次数、答对率 |
| 识字 | 字库里每个字的掌握情况；点一下可以手动标记“认识 / 不认识” |
| 数学、英语 | 各项内容的答对率和当前难度 |
| 打印 | 按周一次打印这一周要用的纸；也可以单独打印涂色页、控笔练习、绘本、描红、数学练习、英语卡片（A4） |
| 设置 | 孩子的名字、每天时长上限、语速、语音选择和试听 |
| 数据 | 导出、导入、清空学习记录；观察笔记 |

建议第一次使用时，先在“识字”里把您确定他认识的字标一遍，这样“认字”活动一开始就只教他不会的字。

## 第 1–2 周有什么

| | 第 1 周　你好，车车镇 | 第 2 周　大石头挡路了 |
| --- | --- | --- |
| 故事 | 《小风来到车车镇》＋ 问答 | 《大石头挡路了》＋ 问答 |
| 识字 | 车 大 小 山 火 水 土 风；找字小侦探 | 石 上 下 来 去；认新字 |
| 数学 | 数车车、停车场、找数字 | 谁多谁少、数字公路、又来了几辆 |
| 英语 | car bus truck；red blue yellow | one–five；green；a red car |
| 探索 | 红绿灯 | 轮子实验室、找规律 |
| 纸上 | 涂色（含一张列车）、控笔练习、绘本、描红、数一数、英语卡片 | 涂色、画一辆车、绘本、描红、写数字、比多少、英语卡片 |

五个角色都是原创的，名字用的是最基础的汉字：小风（小汽车）、小火（消防车）、小水（洒水车）、阿土（挖掘机）、大山（大卡车）。

## 已知的限制

- **语音依赖设备**。朗读用的是浏览器自带的语音合成，音质和是否有中文语音因设备而异。请先在家长页的“设置”里试听；没有声音时，屏幕上的文字需要家长读给孩子听。
- **语音没有在真实设备上验证过**。开发环境没有扬声器和语音引擎，只验证了“没有语音时流程不会卡住”。
- **记录只在本机**。保存在浏览器里，换设备或清除浏览器数据会丢失，请用“导出记录”备份。无痕模式下不会保存。
- **描红页没有笔顺**，第一次写需要家长示范。
- **楷体依赖系统字体**。苹果设备和 Windows 自带楷体；多数安卓设备没有，会显示成黑体，不影响使用。

## 目录

分成三块：**程序**（`app/`，很少改）、**内容**（`content/`，一直增长）、**规划和记录**（`docs/`）。

```
index.html              入口，双击即可打开
app/                    程序：页面和玩法。内容再多，这里也不用跟着改
  core/                 存储、语音和音效、绘图、课程登记处
  engines/              玩法：选择题、故事阅读、停车场、红绿灯、涂色、轮子实验室
  ui/                   孩子的页面、家长页、打印版式
  css/                  界面样式、打印样式
  main.js               路由和启动
content/                内容：按年级分档
  library/              各年级共用：字库、英语词库、反复出现的练习（按学科分文件）
  k2/                   幼儿园中班（现在）
    grade.js            这个年级的阶段目标
    w01.js              第 1 周：故事、新字新词、五天的安排、打印材料
    w02.js              第 2 周
docs/
  growth-log.md         成长记录：每次的观察和调整决定，按时间往后加
  k2/plan.md            中班大纲
tests/smoke.js          自动把所有活动玩一遍的测试
```

年级的代号和先后：

| 目录 | 年级 | 大约时间 | 状态 |
| --- | --- | --- | --- |
| `k2` | 幼儿园中班 | 2026 年 11 月 – 2027 年 8 月 | 进行中 |
| `k3` | 幼儿园大班 | 2027 年 9 月起 | 升班时再规划 |
| `g1` 起 | 小学一年级起 | 2028 年 9 月起 | 到时候再规划 |

没开始的年级不建目录，也不提前写内容。

## 怎么加一周内容

1. 先看 `docs/growth-log.md` 最后一条记录，再对照这个年级的大纲，定这一周教什么。
2. 复制上一周的文件，改成新的一周，例如 `content/k2/w03.js`。里面依次是：故事、这一周新教的字和词、五天的安排、打印材料。
3. 新字如果不在字库里，加到 `content/library/zh-chars.js`；新的英语词加到 `content/library/en-words.js`。
4. 在 `index.html` 里加一行 `<script src="content/k2/w03.js"></script>`，放在上一周的后面。
5. 运行测试，确认每个活动都能走通：

```bash
node tests/smoke.js
```

测试需要 [Playwright](https://playwright.dev/)。忘了第 4 步、活动 id 写错或重复，测试都会直接报出来。

## 升到下一个年级时

1. 在 `docs/growth-log.md` 里写一条回看：这个年级学到了哪里、喜欢什么、不喜欢什么。
2. 据此写下一个年级的大纲，例如 `docs/k3/plan.md`。
3. 新建 `content/k3/grade.js`（照 `content/k2/grade.js` 写）和第一周的文件，在 `index.html` 里加载。

上一个年级没做完的内容不用补做；有用的并进新年级的大纲。
