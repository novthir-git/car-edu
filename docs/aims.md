# 培养目标

这份文件回答一个问题：做这个项目，是想让他长成什么样。

- 大纲（`<年级>/plan.md`）定教什么、怎么排；[成长记录](growth-log.md)定快慢；这份定方向。三者有出入时：方向听这份的，快慢听记录的，大纲跟着改。
- 现在是 2026 年 11 月的工作版本。家长指出“目的没有定”，并把这件事交给做的人通盘考虑；下面是据此定的，家长还没有逐条确认。家长要改哪一条，先在成长记录里追加一条，再改这里。
- 做新内容之前，读“三层”和“起冲突时怎么取舍”两节就够。最后的“依据”是备查的。

## 一句话

到他上小学的时候，是一个**愿意学、坐得住、说得出、想得清、手上稳、处得来、有点子**的孩子，同时带着够用的字、数和英语的底子。

（按现在的年级推算，上小学是 2028 年 9 月。）

## 三层，先保上面的

| 层 | 回答什么 | 包括 |
| --- | --- | --- |
| 一、学习品质 | 他怎么学 | 愿意学、坐得住 |
| 二、能力 | 他能做什么 | 说得出、想得清、手上稳、处得来、有点子 |
| 三、知识 | 他知道什么 | 字、数、英语 |

排这个顺序的理由：

- 第三层晚几个月补得回来，小学会从头教。第一层被催、被比磨掉以后，最难找回。
- 第三层最容易数出来（认了几个字、答对率多少），所以最容易不知不觉变成唯一的目标。这个项目开头两周就是这样：能自动记下来的只有知识点。
- 这不是说知识不重要。字、数、英语照常按大纲教，只是不拿数量当成绩，也不为了数量牺牲上面两层。

## 七个方面

家长问过的“专注度”在**坐得住**里，“逻辑思维”在**想得清**里。

| 方面 | 指什么 | 为什么在这个年纪要紧 |
| --- | --- | --- |
| 愿意学 | 好奇，自己想玩想问，答错了肯再试 | 往后十几年的学习都靠它推着走 |
| 坐得住 | 专心，把一件事做完，能等，记得住规则并照着做 | 上小学第一天就用得上；研究里它和以后的学业有稳定的关系 |
| 说得出 | 听得懂，讲得清，爱听故事、爱翻书。认字和英语听说都算在这里 | 口语是阅读理解的底子；这个年纪的逻辑也要靠“因为……所以……”说出来 |
| 想得清 | 数感（数量、比较、分与合），逻辑（分类、排序、规律、因果），空间，先猜再试 | 入学前的数概念，是预测以后学业最稳定的指标之一 |
| 手上稳 | 握笔、控笔、剪、折 | 写字的前提；手上的小肌肉这两年还在长，要靠真的动手 |
| 处得来 | 说得出自己的情绪，肯轮流、合作，守规则，做不到会求助，懂安全 | 上学以后天天用，也关系到他愿不愿意去学校 |
| 有点子 | 画自己想的，编故事，自己拿主意 | 屏幕上的题都有标准答案，没有标准答案的事要特意留出来 |

## 起冲突时怎么取舍

1. **兴趣和进度冲突，进度让路。** 他连着几天不想开始，或者中途退出变多，先减量、换形式，不加码，也不补。
2. **屏幕和纸、户外、睡觉冲突，屏幕让路。** 每天的时间上限不因为“内容做多了”而调高。
3. **太简单了，先加深，再加快。** 答对率一直很高时，已经会的直接跳过，然后让他讲讲是怎么想的、换一种玩法、去自由玩里挑难的。不把后面年级的内容整块提前。
4. **不考他，不比他。** 大纲里的数字不拿来问他“会了几个”，也不和别的孩子比。没有标准答案的事（画、编、讲）不打分。
5. **说不出服务哪一条的内容，不做。** 新活动要能指到七个方面里的某一个，或者第三层。

## 三条路：屏幕、纸、人

| 路 | 擅长什么 | 主要管哪些方面 |
| --- | --- | --- |
| 屏幕（每天约 10 分钟） | 故事的引子；字、数、词的反复练习，马上有回应；自动记录 | 第三层；想得清；说得出里的“听”和认字 |
| 纸 | 握笔、涂、描、画、剪；一件要花上几分钟的事 | 手上稳；坐得住；有点子 |
| 人（家长） | 听他讲、接着问；一起玩有规则的游戏；路上随口教；观察 | 说得出里的“说”；处得来；愿意学；坐得住 |

- 七个方面里，屏幕直接练得到的不到一半。所以这个项目不能只是一个应用：纸和家长这两条路要编进每一周，不是附带的。
- 不归这个项目管、但不能被它挤占的：跑跳和户外、和小朋友玩、自己吃饭穿衣收拾。这些靠幼儿园和日常生活。

## 家长怎么陪

1. 夸他做的事，不夸聪明：“你数得很仔细”“这个字你试了两次就找到了”。
2. 他答错了，先等几秒，不急着说答案。
3. 多问“你怎么知道的”“为什么”，少问“对不对”。
4. 他讲得短，就把他的话补完整再说一遍，不纠正。
5. 他不想玩就停，第二天不提。
6. 能一起看就一起看。大人在旁边搭话，比他一个人对着屏幕学得多。

## 怎么知道走对了没有

- **屏幕记得到的**：第三层的掌握情况；各类活动他自己选了几次、玩多久、有没有中途退出。后几样只是“愿意学”“坐得住”的旁证，不是直接的量度。
- **屏幕记不到的**（其余大部分）：靠家长看。平时想到就在家长页的观察笔记里记一句；每 12 周对着本年级大纲里“这一年想看到的样子”过一遍，结论写进成长记录。
- 不做测验，不给孩子打等级。看的是“比三个月前多了什么”，不是“达没达标”。

## 对做内容的要求

- 每一周对照七个方面看一遍：故事带一个“心事”（处得来）；有一项逻辑（想得清）；有一张要花几分钟的纸（手上稳、坐得住）；有一件由他定、没有标准答案的事（有点子、愿意学）。缺了就补，补的东西不一定占屏幕上的位置。
- “说”和“处得来”屏幕练不到，要靠家长。给家长的提示（聊什么、屏幕外玩什么、这周留意什么）用什么形式给，还没定，见成长记录。
- 不为了补某个方面去加屏幕时间。

## 各年级的侧重（暂定）

- **中班（现在）**：第一层为主；第二层各方面都碰一碰，找出他偏爱和偏弱的；第三层跟着故事走。
- **大班**：加上入学准备——听完再做、把交代的事记住做完、整理自己的东西、会写自己的名字。到时候“不说任务”这一条要和家长重新商量：入学准备要孩子能把交代的事记住、做完。
- **一年级以后**：学校管第三层的主线，这个项目退到兴趣和拓展。

## 依据：业界的体系

上面的七个方面不是新发明的，是把业界通行的几套体系合起来，换成家里说的话。业界的体系分四类，各解决一个问题。

### 一、官方课程框架：培养什么

| 这里的说法 | 中国《3–6 岁儿童学习与发展指南》 | 英国 EYFS | 美国 Head Start 框架（ELOF） |
| --- | --- | --- | --- |
| 愿意学、坐得住 | 学习品质（写在说明里，贯穿各领域） | “有效学习的特征”；个人、社会和情感发展里的自我调节 | 学习品质（含自我调节、主动与好奇、创造力） |
| 说得出 | 语言 | 沟通与语言；读写 | 语言与读写 |
| 想得清 | 科学（科学探究、数学认知） | 数学；认识世界 | 认知（数学、科学推理） |
| 手上稳 | 健康（动作发展） | 身体发展 | 感知、动作与身体发展 |
| 处得来 | 社会 | 个人、社会和情感发展 | 社会与情感发展 |
| 有点子 | 艺术 | 艺术表达与设计 | 归在学习品质的创造力里 |

- 其他同类框架：新加坡 NEL（学习领域之外单列学习品质）、新西兰 Te Whāriki（用“学习故事”做观察记录）、IB PYP（3–12 岁，跨学科主题探究）。
- 这些框架结构很一致：五六个发展领域，再单列学习品质。没有哪一套把识字量和算术当作学前的主目标。
- 专注和自控在各家都归在学习品质（或自我调节）里；逻辑归在认知、数学里。

### 二、教学流派：怎么教

| 流派 | 核心做法 | 这个项目借什么 | 不借什么 |
| --- | --- | --- | --- |
| 蒙台梭利 | 自己选工作，不被打断地做完；教具自己能看出对错；从实物到抽象 | 一站里先玩哪个由他选；答错不打叉，自己再试；动手的事用纸和实物 | 整套教具和混龄教室，家里做不了 |
| 瑞吉欧 | 跟着孩子的兴趣做项目；老师持续做记录 | 从他喜欢的车出发；成长记录 | — |
| HighScope | 计划—做—回顾：先说打算玩什么，玩完讲一讲 | 一站可以这样用：他选 → 玩 → 讲给家长听 | — |
| 华德福 | 节奏、想象、讲故事、手工；7 岁前不教读写，不用屏幕 | 故事和手工的分量；屏幕要少 | 它反对这个年纪用屏幕学习、提前识字，这个项目在这一点上和它相反，所以屏幕压在每天十来分钟 |
| 安吉游戏、Tools of the Mind | 让孩子真的自己玩，玩后回顾；用有规则的游戏练自控 | 屏幕外有规则的游戏；玩后讲一讲 | — |

### 三、学科的进阶体系：先学什么后学什么

| 学科 | 业界的做法 | 这个项目现在 |
| --- | --- | --- |
| 数学 | “学习轨迹”研究给出的顺序：点数 → 按数取物 → 比较 → 分与合 → 加减。新加坡数学的 CPA：实物 → 图 → 符号。公文式：小步子、大量重复 | 顺序一致。停在“图”这一步，实物要靠家里的玩具车。不走大量重复的路。还缺“一眼看出几个”，图形和空间排在后面的周 |
| 逻辑思维 | 国内的思维训练（何秋光的练习册、逻辑狗、各家思维课）通常拆成：观察比较、分类、排序、规律、对应、空间图形、简单推理 | 只有“找规律”一项。以后按这几块每周轮一项 |
| 中文识字 | 学前没有统一的分级标准。通行做法是高频字优先、在故事里认（洪恩识字、四五快读等）。小学课标：一二年级认识 1600 个左右常用字 | 做法一致。每周的打印绘本只用教过的字，相当于自己的分级读物 |
| 英语 | 先大量听（儿歌、绘本、动画），再读分级读物（牛津树、RAZ）、学自然拼读；学前不要求拼写 | 只有单词和短语，听的量太少，合成语音的质量也有限。这是弱项，值得另找儿歌和绘本补 |
| 读故事 | 对话式阅读：大人提问、把孩子的话补完整、再说一遍。问题分回忆的、“为什么”的、联系他自己的 | 故事问答只有回忆题。另外两种屏幕判不了对错，要家长来问 |
| 专注和自控 | 规则中途会变的游戏（比如“红灯绿灯”玩熟了反着来）；玩之前先说打算 | “红绿灯”只有固定规则 |
| 社会情感 | 通行的五项：认识自己、管住自己、理解别人、处好关系、做负责的决定。常用绘本加“说出情绪” | 两个故事里都有，但没有说破 |

### 四、同类产品：用什么形式

- 国内的互动启蒙课（斑马、叫叫、小猴启蒙等）普遍是：按年龄分级，每周一个主题，每天一节十几分钟，配寄到家的练习册和教具，给家长学习报告。这个项目的骨架和它们一样。
- 差别在于这个项目只为一个孩子做：可以跟着他的兴趣和反应改，不用赶统一的进度；代价是内容少，要一批一批地做。
- 海外的 Khan Academy Kids 覆盖读写、数学、社会情感、执行功能，可以当作“全方位”在屏幕上能做到什么程度的参照。
